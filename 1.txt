Q19. Write a Python program to create a TCP Echo Server that accepts a
client, receives a message, and sends the same message back. Code:
import socket

ip = “127.0.0.1” port = 
5000

server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

server.bind((ip, port)) server.listen(1)

print(“Server is waiting for a connection…”)

connection, address = server.accept() print(“Connected to:”, 
address)

data = connection.recv(1024) print(“Received:”, data.decode())

connection.sendall(data)

connection.close() server.close()
