Q17. Complete Practical Exercise:
Write a program that asks the user for a hostname
or IPv4 address and an IPv4 network, resolves the
hostname, displays network information, and checks
whether the IP belongs to the network.

ANSWER:

import socket
import ipaddress

try:
    host = input("Enter hostname or IPv4 address: ")
    network_input = input("Enter IPv4 network: ")

    try:
        ip = ipaddress.ip_address(host)
    except ValueError:
        ip = ipaddress.ip_address(
            socket.gethostbyname(host)
        )

    network = ipaddress.ip_network(network_input)

    print("IP Address:", ip)
    print("IP Version:", ip.version)

    print("Network Address:", network.network_address)
    print("Subnet Mask:", network.netmask)
    print("Total Addresses:", network.num_addresses)

    if ip in network:
        print("IP belongs to the network")
    else:
        print("IP does not belong to the network")

except (ValueError, socket.gaierror):
    print("Invalid hostname, IP address, or network")

Q19. Write a Python program to create a TCP Echo
Server that receives a message and sends the same
message back to the client.

ANSWER - SERVER:

import socket

server_socket = socket.socket(
    socket.AF_INET,
    socket.SOCK_STREAM
)

server_socket.bind(("127.0.0.1", 5000))

server_socket.listen()

print("Server is waiting for a connection...")

client_socket, address = server_socket.accept()

print("Connected by:", address)

data = client_socket.recv(1024)

print("Received:", data.decode())

client_socket.sendall(data)

client_socket.close()
server_socket.close()


Q20. Write a Python program to create a TCP Client

Q22. Modify the TCP Client program to handle
connection errors using try and except.

ANSWER:

import socket

client_socket = socket.socket(
    socket.AF_INET,
    socket.SOCK_STREAM
)

try:
    client_socket.connect(("127.0.0.1", 5000))

    message = input("Enter message: ")

    client_socket.sendall(message.encode())

    data = client_socket.recv(1024)

    print("Server Response:", data.decode())

except ConnectionRefusedError:
    print("Connection failed! Server is not running.")

except OSError as error:
    print("Network Error:", error)

finally:
    client_socket.close()


Q23. Write a TCP Echo Server using the with
statement to automatically close the server socket.

ANSWER:

import socket

with socket.socket(
    socket.AF_INET,
    socket.SOCK_STREAM
) as server_socket:

    server_socket.bind(("127.0.0.1", 5000))

    server_socket.listen()

    print("Server is waiting for a connection...")

    client_socket, address = server_socket.accept()

    with client_socket:
        print("Connected by:", address)

        data = client_socket.recv(1024)

        print("Received:", data.decode())

        client_socket.sendall(data)

Returns the local computer hostname.

Resolves a hostname into an IPv4 address.

Retrieves address information for a host.

Handles address-resolution errors.

Creates an IP address object.

ipaddress.ip_network(value)

Returns the IP version (4 or 6).

.netmask
Returns the subnet mask.

.broadcast_address
Returns the broadcast address.

.num_addresses
Returns the total number of addresses.

Uses IPv4.

socket.SOCK_STREAM
Uses TCP.

bind()
Assigns an IP address and port to the server.

listen()
Puts the server into listening mode.

accept()
Waits for a client connection.

connect()
Connects the client to the server.

sendall()
Sends data through the connection.

recv(1024)
Receives up to 1024 bytes.

encode()
Converts text into bytes.

decode()
Converts bytes into text.

close()
Closes the socket.

settimeout(5)
Sets a five-second timeout.

setsockopt()
Configures socket options.
